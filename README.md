# Loop Echo (working name)

A single-PT2399 delay with an **effects loop in the feedback path**:
- only the repeats circulate through the loop;
- the first echo is clean, and each later echo goes through the external effect again: fuzz degrades, a filter re-voices, a pitch shifter cascades;
- delay-time modulation (RATE, DEPTH);
- true bypass.

The PT2399 network is taken from your Small Time (`~/Documents/eagle/projects/Small Time/`, 2022), without its tails JFET.

- **Schematic:** [docs/LoopEcho_schematic.pdf](docs/LoopEcho_schematic.pdf), generated by `scripts/build_loopecho.py`. ERC 0.
- **Notes:** [docs/Design Notes.md](docs/Design%20Notes.md).

**Controls:** TIME (B50k), REPEAT (B10k), MIX (B10k), RATE (B1M), DEPTH (B100k). That's five knobs: the 125B five-knob grid.

**Jacks:** IN, OUT, DC, plus one **TRS insert** jack (tip = send, ring = return, use a Y-cable).

**Status:** v0.1 schematic (2026-10-07), breadboard next. The modulation will be compared with your mod examples.
